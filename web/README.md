# Shuriken School — Première mission jouable v0.2

**La furie des tongs** est un prototype jouable **en solo** sur navigateur PC et mobile, avec graphismes vectoriels temporaires originaux.

## Démarrer
Ouvrir `index.html` dans un navigateur moderne, ou publier le dossier `web/` sur un hébergement statique HTTPS (PWA hors ligne après première visite).

## Contrôles
PC : WASD / flèches pour se déplacer, touches 1/2/3 (ou Q) pour changer de héros, E pour interagir, Espace pour la technique, K/J/F pour lancer un projectile d'entraînement, Échap pour la pause. Mobile : boutons tactiles sur le jeu.

## Fonctionnalités
Trois personnages et compétences distinctes, trois indices, déchiffrage par Okuni, grille vers Katana School, tongs à récupérer, gardes patrouillant et poursuivant le joueur, points de contrôle, santé, victoire/défaite, sons facultatifs.

## Limites
Ceci est un **prototype non officiel** et non le jeu final. Pas encore de coop en ligne ni d'assets authentifiés de la série. Les graphismes sont des substituts originaux temporaires ; les événements jouables restent à comparer aux épisodes pour atteindre l'objectif de fidélité. Le vieux prototype réseau LAN Godot dans `../game/` est une branche technique distincte et n'est pas intégré à cette version navigateur.
