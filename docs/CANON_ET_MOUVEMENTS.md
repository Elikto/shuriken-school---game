# Shuriken School : registre du canon, mouvements et dialogues

## Principe

Le but est la **fidélité maximale** à la série, mais aucune action, capacité ou réplique ne peut être annoncée « 100 % canonique » sans un **épisode, un timecode et une source**. Ne pas générer de citations fictives.

| Élément | État de l'attestation | Implémentation du prototype |
| --- | --- | --- |
| Eizan, Okuni, Jimmy B (trio) | Personnages attestés dans la série | Sélection de nom/compétence provisoire |
| Personnalité et objets caractéristiques | À détailler avec images de référence et épisodes | Modèles géométriques provisoires uniquement |
| Course et acrobaties ninja | Généralement cohérentes avec le genre ; mouvements exacts à relever | Déplacement et saut |
| Course sur les murs (Eizan) | **CONFIRMÉ, niveau synopsis** : description Apple TV France dit qu'Eizan « court sur les murs » ; épisode/timecode exact à retrouver | Wall-run réservé à Eizan ; implémentation gestuelle à calibrer sur les épisodes |
| Camouflage / nuage de fumée (Eizan) | **CONFIRMÉ, niveau synopsis** : description Apple TV France évoque l'intégration au décor et le nuage de fumée | Invisibilité temporaire gameplay (durée de 3 secondes = ADAPTATION à tester) |
| Esquive et combat contre vagues | **ADAPTATION** du genre horde, pas un événement canonique constaté | Esquive, mêlée, 3 vagues |
| Techniques héros | **ADAPTATION**, noms de compétence non officiels | Attaque radial / stun / dash |
| Coffres avec récompenses | **ADAPTATION** de game design | Coffres santé/pièces |
| Grand boss « champion rival » | **ADAPTATION**, non attribué à une scène précise | Boss provisoire |
| Dialogues d'épisodes | **NON RECENSÉS** | Aucun dialogue officiel copié ; interfaces originales |

## Cahier de dépouillement à remplir

Pour chaque épisode : `id`, `titre original`, `source autorisée`, `timecode début/fin`, `personnage`, `mouvement`, `conditions`, `interaction`, `dialogue (résumé)`, `preuve`, `statut juridique`.

Mouvements à relever : marche, sprint, saut, double saut éventuel, saut mural, course murale, escalade, roulade, esquive, glissade, corde, planche, déguisement, saut acrobatique, armes/objets de la série, animations d'attente, expressions et interactions comiques. **Ne les ajouter au statut canonique qu'après contrôle.**

Dialogues : documenter l'intention, l'émotion et le déroulement narratif ; pour intégrer les lignes originales, obtenir les droits nécessaires sur les textes/voix. En attendant, seules des formulations inédites clairement identifiées comme adaptations sont admissibles.
